## Problem

Building a workable class schedule requires comparing meeting patterns, unavailable times, preferences, and changing course information across many possible combinations.

## Solution

Class Planner combines course meeting information with student preferences and unavailable times to generate schedule alternatives that can be compared, refined, saved, shared, and exported.

This page includes Class Planner as a production campus-app example. Its public documentation describes a scheduling service; it is not presented here as an AI system making enrollment decisions.

## Current status

In production. Students remain responsible for reviewing TBA meetings, warnings, changing availability, and other details before enrollment.
