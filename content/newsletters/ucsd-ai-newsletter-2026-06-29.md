## What's New in Your AI Tools

### Zoom AI Companion

-   **AI Companion name retired; features stay under "AI"**: Zoom's June 2026 update drops the "AI Companion" branding. Meeting Summaries, Chat Compose, Scheduling Assistance, and Smart Recording remain under the "AI" label. A catch-up prompt now offers late joiners a summary of what they missed. The mobile app also adds Zoom Slides, Sheets, and Paper. Admins can disable AI features automatically when certain restricted users join a meeting.

### Microsoft Copilot with Data Protection

-   **[Anthropic's Claude now available in Copilot Chat](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes)** — Claude is now a model option in Copilot Chat for document work and multi-step analysis. You can select it on Android, Windows, iOS, or Mac. It is also available on the web.

### Copilot for Microsoft 365

-   **[Learning Agent is now generally available](https://techcommunity.microsoft.com/blog/microsoft365copilotblog/learning-agent-now-generally-available-%E2%80%94-personalized-ai-upskilling-for-every-em/4524571)** — Microsoft's Learning Agent recommends training based on your role and work patterns. It appears inside Copilot and Microsoft 365 apps. Each day starts with an AI Tip of the Day tied to the work you do.

### Google Gemini & NotebookLM

-   **[Gemini Enterprise adds Confluence Data Center connector](https://docs.cloud.google.com/gemini/enterprise/docs/release-notes)** — Gemini Enterprise can now search and reference a connected Confluence Data Center instance. The update also adds an Agent Registry for custom MCP servers and agents, along with observability dashboards.

### TritonAI Developer API

-   **[Cohere transcription model added to model hub](https://tritonai-api.ucsd.edu/public/model_hub)** — A new self-hosted Cohere audio transcription model (\`api-cohere-transcribe\`) is now available through the TritonAI API. This adds native audio transcription capability to the platform, running on UCSD's own infrastructure. Developers can integrate speech-to-text into their applications without sending audio data to external services.
