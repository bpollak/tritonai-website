Gateway and TritonAI Harness

Get Gateway access and set up TritonAI Harness

TritonAI Harness is UC San Diego's primary supported Gateway client. Claude Code and Codex are also supported. Hermes, OpenCode, and other compatible clients can connect through the OpenAI-compatible API. Request access, then set up a client. Shared services use TritonAI Developer APIs.

Gateway access comes first.

Your key connects compatible clients to approved models. Approval lists billing and limits. You need the key to finish TritonAI Harness setup.

  1. 1Request access
  2. 2Receive key
  3. 3Choose client
  4. 4Set up TritonAI Harness

Phase 1

Get TritonAI Gateway access

Request your key and approved access.

01

Gateway access

Request access to the TritonAI Gateway

Purpose and funding set access, review, and charges.

  • Purpose: campus administrative work, instruction, sponsored or non-sponsored research, faculty exploration, patient-care operations, or external partner work
  • Funding: sponsored-project status, Campus or Health Sciences affiliation, sponsor, and outside organization when applicable
  • Access: on-premises-only or cloud-enabled. Cloud access requires a chartstring, named budget owner, and spend limit
  • Project: task, owner, users, information, systems, and expected use

How charges work

For campus administrative work, on-premises use is not recharged. Cloud use is charged from the first token at the current market rate published in the Model Hub. Research projects charge both on-premises and cloud model use to a grant or approved research project chartstring. Other UC campuses need an inter-campus recharge agreement and are recharged for both on-premises and cloud model use.

Who can use the TritonAI Gateway

Eligibility depends on affiliation and use.

Eligible for Gateway access

  • UC San Diego faculty and staff: Campus and Health Sciences faculty and staff may use the Gateway for administrative work. Monthly caps apply; unusually high individual or agent activity may be reviewed.

Access by arrangement

  • Other UC campuses: Email tritonai@ucsd.edu about an inter-campus recharge agreement.
  • Other non-UC San Diego participants: Email tritonai@ucsd.edu to ask about access and funding.

Use Medical Center services

Medical Center clinical and patient-care operations: The TritonAI Gateway and TritonAI Harness are not the supported paths for patient-care operations or other health system use cases. Use Medical Center platforms and the supported AI services on Pulse.

Data: TritonAI can consider P1 through P3 data within an approved setup; P4 data is not approved.

Submit the access request

Provide funding and ownership details so the team can assign access and controls.

Request TritonAI Gateway access
02

Gateway approval

Receive and protect your Gateway key

Approval includes your key, access, billing treatment, and limits. Cloud access requires a chartstring, named budget owner, and spend limit; ITS requests also need budget-manager approval. TritonAI Harness can save a second key.

Keep the key private

Treat it like a password. Use it only with an approved client or the TritonAI Installer. Keep it out of prompts, messages, screenshots, and work files. Support will never ask for the full key.

Choose your workspace

Choose how to use the Gateway

Use the client in your approval. The access key is not tied to TritonAI Harness.

Phase 2

Set up TritonAI Harness

Install TritonAI Harness and add your key.

03

Primary supported client

Download the TritonAI Harness installer

Choose the installer for your computer.

Mac

Requires Apple M1 or newer. Check Apple menu → About This Mac. Intel Macs are not supported.

Download for MacCurrent Apple Silicon DMG

Requires an x64 processor. Check Settings → System → About → System type.

Download for WindowsCurrent x64 Setup EXE

Current version. Read the release notes or view the file checks.

04

Platform instructions

Install on your computer

Install on Mac

  1. Open Downloads and double-click the TritonAI Installer DMG.
  2. Double-click TritonAI Installer. Select Open if asked.
  3. Continue to the access-key screen.

Install on Windows

  1. Open Downloads and double-click the TritonAI Installer Setup EXE.
  2. If Microsoft Defender SmartScreen appears, confirm the filename, then select More info and Run anyway. Contact local IT if blocked.
  3. Continue to the access-key screen.
05

Guided setup

Enter the key and finish setup

  1. 1
    Enter the access key

    Paste it into TritonAI access key. For a second key, select I have another access key.

  2. 2
    Check access and install

    Select Check access & install. The Installer verifies your models and sets up TritonAI Harness.

  3. 3
    Keep the Installer open

    Wait for Installation complete.

06

First launch

Open TritonAI Harness and verify access

Select Open TritonAI Harness. Reopen it later from Applications on Mac or the Windows desktop shortcut.

  • Choose a model shown in TritonAI Harness.
  • Try a low-risk task with approved information.
  • Check sources, results, and proposed actions.

The Model Hub lists models and rates. Your approval sets models, limits, and billing treatment.

Setup help

The key is not accepted
Remove extra spaces. Contact support without sending the key.
No models appear
The key may not be active. Contact support.
The installer will not open
Confirm your computer is supported, then download it again.

Need help? Email tritonai@ucsd.edu with your operating system and an error screenshot. Hide any access key.
