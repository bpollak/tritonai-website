Gateway access and Harness setup

Start with Gateway access, then set up TritonAI Harness

TritonAI Harness is UC San Diego's primary supported client for using the Gateway and the recommended path on this page. Claude Code and Codex are also supported. Request Gateway access below, then continue to the Harness installer or configure another supported client. For the service overview and shared development path, see TritonAI Developer APIs.

Gateway access comes first.

Your TritonAI access key connects compatible clients to the models approved for your work. Your approval response also states the funding and billing treatment for the key. You can download the Harness installer while your request is pending, but you need the key to finish Harness setup.

  1. 1Request Gateway access
  2. 2Receive your key
  3. 3Choose a client
  4. 4Set up Harness

Phase 1

Get TritonAI Gateway access

Submit the intake and receive your key, approved models, billing treatment, limits, and data controls.

01

Gateway access

Request access to the TritonAI Gateway

The request opens the UC San Diego sign-in page. The intake classifies access by the purpose and funding source for the work. Department and Health Sciences affiliation provide context, while the intended use determines the review and funding path.

  • Purpose: campus administration, instruction, sponsored research, non-sponsored research or faculty exploration, clinical or patient-care operations, or external partner work
  • Affiliation and funding: sponsored-project status, campus or Health Sciences affiliation, sponsor, and external organization when applicable
  • Requested access: on-premises-only or cloud-enabled. Cloud access requires a chartstring, named budget owner, and spend limit
  • Project details: task, outcome, owner, audience, information, systems, and expected usage

How charges work

For campus administrative work, on-premises token use is covered and not recharged. Cloud use is charged from the first token at the current market rate published in the Model Hub. Research projects charge both on-premises and cloud model use to a grant or approved research project chartstring. Other UC campuses may use the Gateway through an inter-campus recharge agreement and are recharged for both on-premises and cloud model use.

Who can use the TritonAI Gateway

Access depends on your affiliation and whether the work is administrative, research, or clinical.

Eligible for Gateway access

  • UC San Diego faculty and staff: Campus and Health Sciences faculty and staff may use the Gateway for administrative work. For UC San Diego administrative work, on-premises model use is not recharged. Monthly caps apply, and unusually high individual or agent activity may be reviewed to keep usage within supported limits. Cloud model use is charged at the current rate published in the Model Hub.

Access by arrangement

  • Other UC campuses: Email tritonai@ucsd.edu to discuss participation. Other UC campuses may use the Gateway through an inter-campus recharge agreement and are recharged for both on-premises and cloud model use.
  • Other non-UC San Diego participants: Email tritonai@ucsd.edu to ask whether a supported access and funding path is available.

Use Medical Center services

Medical Center clinical and patient-care operations: The TritonAI Gateway and Harness are not the supported paths for clinical, patient-care, or other health system use cases. Use Medical Center platforms and review the supported AI services on Pulse.

Data: TritonAI can consider P1 through P3 data within an approved setup; P4 data is not approved.

Submit the access request

Complete funding and ownership details help the team assign the correct access, controls, and approval path.

Request TritonAI Gateway access
02

Gateway approval

Receive and protect your Gateway key

If your request is approved, you will receive a key and setup instructions. The response identifies your approved on-premises or cloud access, billing treatment, and any spending or review limits. Cloud access requires the approved chartstring, named budget owner, and spend limit. ITS cloud requests also follow the TritonAI budget-manager approval path. Most people receive one key. If you receive two and choose Harness, the Installer can save both.

Keep the key private

Treat it like a password. Use it only with an approved client or the TritonAI Installer. Do not put it in prompts, email, chat, screenshots, or work files. Support will never ask for the full key.

Choose your workspace

Choose how to use the Gateway

Use the client listed in your setup instructions. The access key is not tied to Harness.

Phase 2

Set up TritonAI Harness

Download the installer, add your key, and verify your approved model access.

03

Recommended client

Download the TritonAI Harness installer

Select the supported package for your computer. These buttons download the installer file directly.

Mac

For Mac computers with an Apple M1 chip or newer. Choose Apple menu → About This Mac to check. Intel Macs are not supported.

Download for MacCurrent Apple Silicon DMG

Signed by the developer and checked by Apple.

Windows

For Windows computers with an x64 processor. Check Settings → System → About → System type if you are unsure.

Download for WindowsCurrent x64 Setup EXE

The current Windows installer is not signed. Windows may show a Microsoft Defender SmartScreen warning.

Current version. Read the release notes or view the file checks.

04

Platform instructions

Install on your computer

Install on Mac

  1. Open Downloads and double-click the TritonAI Installer DMG.
  2. In the window that opens, double-click TritonAI Installer.
  3. If macOS asks for confirmation, select Open.
  4. Continue to the access-key screen.

Install on Windows

  1. Open Downloads and double-click the TritonAI Installer Setup EXE.
  2. If SmartScreen appears, confirm the filename came from the download button on this page.
  3. If your department allows this installer, select More info, then Run anyway. Contact local IT if Windows blocks it.
  4. Continue to the access-key screen.
05

Guided setup

Enter the key and finish setup

  1. 1
    Enter the access key

    Paste the key into the box labeled TritonAI access key. If you received two keys, select I have another access key.

  2. 2
    Check access and install

    Select Check access & install. The Installer checks which models you can use and sets them up.

  3. 3
    Keep the Installer open

    Leave the Installer open until you see Installation complete. It installs the Harness and the campus tools it needs.

06

First launch

Open Harness and verify access

When you see Installation complete, select Open TritonAI Harness. You can open it later from Applications on Mac or the desktop shortcut on Windows.

  • Choose a model shown in Harness.
  • Try a small, low-risk task using information you are allowed to use.
  • Check the sources, results, and proposed actions before doing more.

The Model Hub lists current models and published rates. The models, limits, and billing treatment you receive depend on the access approved for your key.

Setup help

The key is not accepted
Copy it again without leading or trailing spaces. If it still fails, contact support without including the key.
No models appear
Your key may not be active for any models. Contact support and describe the request you submitted.
The installer will not open
Confirm that your computer matches a supported platform and that you downloaded the installer from this page.

Need help? Email tritonai@ucsd.edu with your operating system and a screenshot of the error. Remove or cover any access key before sending the screenshot.
