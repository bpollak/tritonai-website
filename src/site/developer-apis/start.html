TritonAI Harness setup

Get access, install, and open the Harness

TritonAI Harness is UC San Diego's main desktop app for working with AI agents. The installer sets up the app, campus tools, and the models you are allowed to use.

An active TritonAI access key is required.

The key lets the Harness connect to the AI models approved for your work. You can download the installer while your request is pending, but you need the key to finish setup.

  1. 1Request access
  2. 2Download
  3. 3Install
  4. 4Open Harness
01

Request access

Request a TritonAI access key

The request opens the UC San Diego sign-in page. Tell us what you want to do, who will use the result, and what information or systems are involved. This helps the team decide which models and access you need.

  • Your UC San Diego login and department or sponsor
  • The task and intended outcome
  • Who will use or review the work
  • The information and systems it needs

Submit the access request

Some requests take longer if they need extra privacy, security, accessibility, or support review.

Request a TritonAI access key
02

Approval response

Receive and protect the key

If your request is approved, you will receive a key and setup instructions. Most people receive one key. If you receive two, the Installer can save both.

Keep the key private

Treat it like a password. Enter it only in the TritonAI Installer. Do not put it in prompts, email, chat, screenshots, or work files. Support will never ask for the full key.

03

Choose your computer

Download the TritonAI Harness installer

Select the supported package for your computer. These buttons download the installer file directly.

Mac

For Mac computers with an Apple M1 chip or newer. Choose Apple menu → About This Mac to check. Intel Macs are not supported.

Download for MacCurrent Apple Silicon DMG

Signed by the developer and checked by Apple.

Windows

For Windows computers with an x64 processor. Check Settings → System → About → System type if you are unsure.

Download for WindowsCurrent x64 Setup EXE

The current Windows installer is not signed. Windows may show a Microsoft Defender SmartScreen warning.

Current version. Read the release notes or view the file checks.

04

Platform instructions

Install on your computer

Install on Mac

  1. Open Downloads and double-click the TritonAI Installer DMG.
  2. In the window that opens, double-click TritonAI Installer.
  3. If macOS asks for confirmation, select Open.
  4. Continue to the access-key screen.

Install on Windows

  1. Open Downloads and double-click the TritonAI Installer Setup EXE.
  2. If SmartScreen appears, confirm the filename came from the download button on this page.
  3. If your department allows this installer, select More info, then Run anyway. Contact local IT if Windows blocks it.
  4. Continue to the access-key screen.
05

Guided setup

Enter the key and finish setup

  1. 1
    Enter the access key

    Paste the key into the box labeled TritonAI access key. If you received two keys, select I have another access key.

  2. 2
    Check access and install

    Select Check access & install. The Installer checks which models you can use and sets them up.

  3. 3
    Keep the Installer open

    Leave the Installer open until you see Installation complete. It installs the Harness and the campus tools it needs.

06

First launch

Open Harness and verify access

When you see Installation complete, select Open TritonAI Harness. You can open it later from Applications on Mac or the desktop shortcut on Windows.

  • Choose a model shown in Harness.
  • Try a small, low-risk task using information you are allowed to use.
  • Check the sources, results, and proposed actions before doing more.

The Model Hub lists current models. The models you see in Harness depend on the access approved for your key.

Setup help

The key is not accepted
Copy it again without leading or trailing spaces. If it still fails, contact support without including the key.
No models appear
Your key may not be active for any models. Contact support and describe the request you submitted.
The installer will not open
Confirm that your computer matches a supported platform and that you downloaded the installer from this page.

Need help? Email tritonai@ucsd.edu with your operating system and a screenshot of the error. Remove or cover any access key before sending the screenshot.
