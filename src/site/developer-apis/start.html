TritonAI Harness setup

Get access, install, and open the Harness

TritonAI Harness is UC San Diego's primary supported desktop workspace for AI agent work. The guided installer handles the managed runtime, campus skills, and model routing for your approved access.

An active TritonAI access key is required.

The access key is the API token Harness uses to connect to models through the TritonAI LLM Gateway. You can download the installer while your request is pending, but setup cannot finish without an active key.

  1. 1Request access
  2. 2Download
  3. 3Install
  4. 4Open Harness
01

Gateway access

Request a TritonAI access key

The request opens UC San Diego Single Sign-On. Be ready to describe the work so the service team can review the appropriate model route and data handling requirements.

  • Your UC San Diego identity and department or sponsor
  • The task and intended outcome
  • The people who will use or review the result
  • The data and systems the work requires

Submit the access request

Review timing depends on the use case and any privacy, security, accessibility, or service-owner review.

Request a TritonAI access key
02

Approval response

Receive and protect the key

When your request is approved, use the access key and model-route guidance provided with the approval. Most people receive one key. If your approved work uses separate routes and you receive another key, the Installer can store both.

Keep the key private

Treat the key like a password. Enter it only in the TritonAI Installer. Keep it out of prompts, email, chat, screenshots, project files, and source code. Support staff will never need the full key to troubleshoot setup.

03

Choose your computer

Download the TritonAI Harness installer

Select the supported package for your computer. These buttons download the installer file directly.

Mac

For Macs with Apple Silicon. Choose Apple menu → About This Mac; the Chip field must show Apple M1 or newer. Intel Macs are not supported.

Download for MacCurrent Apple Silicon DMG

Developer ID signed, Apple notarized, and stapled.

Windows

For Windows computers with an x64-based processor. Check Settings → System → About → System type if you are unsure.

Download for WindowsCurrent x64 Setup EXE

The current Windows installer is unsigned, so Microsoft Defender SmartScreen may appear.

Current version. Read the release notes or verify the SHA-256 checksums.

04

Platform instructions

Install on your computer

Install on Mac

  1. Open Downloads and double-click the TritonAI Installer DMG.
  2. In the window that opens, double-click TritonAI Installer.
  3. If macOS asks for confirmation, select Open.
  4. Continue to the access-key screen.

Install on Windows

  1. Open Downloads and double-click the TritonAI Installer Setup EXE.
  2. If SmartScreen appears, confirm the filename came from the download button on this page.
  3. If your department permits the unsigned package, select More info, then Run anyway. Contact local IT if your policy blocks it.
  4. Continue to the access-key screen.
05

Guided setup

Enter the key and finish setup

  1. 1
    Enter the access key

    Paste the approved key into TritonAI access key. Select I have another access key only if the approval included a second key.

  2. 2
    Check access and install

    Select Check access & install. The Installer checks which models the key can use and configures the correct routing automatically.

  3. 3
    Keep the Installer open

    Setup installs the managed runtime, campus skills, and Harness application. Wait for Installation complete.

06

First launch

Open Harness and verify access

Select Open TritonAI Harness when installation finishes. You can open it later from Applications on macOS or the desktop shortcut on Windows.

  • Choose a model shown as available in Harness.
  • Start with a low-risk task and information you are approved to use.
  • Review sources, results, and proposed actions before expanding the workflow.

The Model Hub lists current models and hosting. The models available in Harness depend on the routes approved for your key.

Setup help

The key is not accepted
Copy it again without leading or trailing spaces. If it still fails, contact support without including the key.
No models appear
The key may not include an active model route. Contact support and describe the request you submitted.
The installer will not open
Confirm that your computer matches a supported platform and that you downloaded the installer from this page.

Need help? Email tritonai@ucsd.edu with your operating system and a screenshot of the error. Remove or cover any access key before sending the screenshot.
