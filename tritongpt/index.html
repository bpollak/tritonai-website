TritonGPT request architecture

How a request moves through the platform

After campus sign-in, TritonGPT sends each request through the TritonAI LLM Gateway. The gateway routes it to an approved model and can add your files, approved campus sources, or bounded assistant tools when the task needs them and your access allows. The response returns to TritonGPT for you to review.
