Contributor checklist

Give direction while the skills handle the mechanics

You prompt and decide

  • Set the content goalName the route, audience, approved source, desired result, and any open decisions.
  • Improve the storyAsk for clearer structure, stronger headings, useful examples, or a more direct audience action.
  • Improve the designAsk for an on-brand composition, accessible workflow visual, or better responsive reading order.
  • Approve the resultReview the preview, diff, evidence, pull request, and live page. An authorized person merges.

Skills handle after the trigger

  • Discover the rulesSelect matching skills, find the canonical source, and preserve routes, brand, accessibility, and integrations.
  • Implement and previewCreate the branch, edit the source, build the site, and keep responsive previews current.
  • Validate and prepare reviewRun required checks and prepare the approved commit, push, and pull request.
  • Follow the releaseAfter the human merge, monitor Cascade and compare production with the approved result.
